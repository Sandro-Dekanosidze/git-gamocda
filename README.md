# Exam Project - Git & GitHub პრაქტიკული დავალება

## პროექტის აღწერა
მოცემული პროექტი შექმნილია Git-ისა და GitHub-ის ვერსიის კონტროლის სისტემის პრაქტიკული გამოყენების დემონსტრირებისთვის.

### ეტაპები:
1. **I ეტაპი:** ლოკალური რეპოზიტორის ინიციალიზება, საბაზისო ფაილების შექმნა და პირველი კომიტი.
2. **II ეტაპი:** ახალი განშტოების (`feature-header`) შექმნა, ცვლილებების შეტანა და შერწყმა `main` განშტოებასთან.
3. **III ეტაპი:** კონფლიქტის პროვოცირება ორ განშტოებას (`nav-feature`, `nav-alt`) შორის, Git-ის მარკერების გაანალიზება და კონფლიქტის გადაჭრა.
